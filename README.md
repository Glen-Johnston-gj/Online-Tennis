# Online Tennis
---

## What is this?
This is a networking project I took on to have fun, I wanted to see if I could do networking in python and connect to clients together to play a game. I made the server for the raspberry pi pico W and it ran well within the same network.

This was a hobby project to make a simple game work over the network.

## How to run

To run this you will need pygame run `pip install pygame`. If you are on linux and want to download pygame globally use `sudo apt install python3-pygame`

configure the IP and port to your liking, ensure the clients have the same lobby and password. Run the server and then run both clients.
